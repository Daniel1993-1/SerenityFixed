# Serenity App (Kotlin + Firebase)

Aplicación Android desarrollada en **Kotlin** con integración de **Firebase Authentication** y **Cloud Firestore**.  
Permite gestionar estados emocionales mediante cuestionarios interactivos y visualizaciones gráficas.  
Proyecto orientado a migración multiplataforma.

---

## 🚀 Instalación y clonación

1. Clonar el repositorio:
   ```bash
   git clone https://github.com/Daniel1993-1/SerenityFixed.git
Abrir el proyecto en Android Studio.

Descargar tu propio archivo google-services.json desde Firebase Console y colocarlo en la carpeta app/.

Ejecutar la aplicación en un emulador o dispositivo físico.

🛠️ Tecnologías usadas
Kotlin

Android Studio

Firebase Authentication

Cloud Firestore

Jetpack Compose

🎯 Objetivos
Construir una aplicación móvil que ayude a los usuarios a registrar y visualizar su estado emocional.

Implementar cuestionarios psicológicos estandarizados (PHQ-9, GAD-7, PSS-10).

Preparar la base para migración multiplataforma.
